# First Model

Educational project

## Предметная область

Таблица **«Автомобили» (cars)** — учёт автомобилей в автосалоне.

| Поле | Тип | Ограничения |
|------|-----|-------------|
| `brand` | STRING | обязательное |
| `model` | STRING | обязательное |
| `year` | INTEGER | — |
| `price` | FLOAT | — |
| `isAvailable` | BOOLEAN | по умолчанию `true` |

## Установка и запуск

```bash
npm install
node index.js
```
